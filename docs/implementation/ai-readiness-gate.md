A use case requires PASS for: product value, canonical rule mapping, owning Context, data readiness, API readiness, security/privacy, output schema, approval mode, manual fallback, evaluation dataset/threshold, observability/quota, feature flag and rollback.

Any FAIL means `NOT READY`; `PASS WITH CONDITIONS` is allowed only for non-production shadow testing.
