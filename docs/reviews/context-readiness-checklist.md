# Gate before business coding

- [ ] Capability outcome and PRD requirements mapped.
- [ ] Context owner and ubiquitous language accepted.
- [ ] Aggregates/invariants/state machines defined.
- [ ] Source-of-Truth and dependencies consistent.
- [ ] Commands/queries/use cases defined.
- [ ] Transaction and concurrency boundaries defined.
- [ ] Candidate data model reviewed; exact Alembic plan assigned.
- [ ] API operations assigned to OpenAPI owner.
- [ ] Events assigned to JSON Schema/AsyncAPI owner.
- [ ] Permissions/scopes/masking/SoD defined.
- [ ] Process managers/reconciliation/manual intervention defined.
- [ ] Audit, Documents, Integration and Operations impacts defined.
- [ ] Acceptance/security/concurrency/reconciliation tests defined.
- [ ] Open decisions affecting scope closed or waived.
