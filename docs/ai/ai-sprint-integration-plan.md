# 1. Foundation sprints

Sprint 0: accept AI ADRs, use-case priorities, data/provider policy and Open Decisions. Sprint 1: create ports, registry schemas and mock provider. Sprint 2: jobs, retry, circuit breaker, Audit and observability. Sprint 3: Platform/IAM configuration, permissions and feature flags.

# 2. Context increments

Activity/Party/Lead unlock summary/transcript/extraction. Product/Matching unlock semantic search and ranking. Transaction unlock Deal risk/NBA. Documents/Contract unlock extraction/review. Analytics unlock natural-language explanation through approved semantic metrics.

# 3. Definition of Ready

No AI implementation task enters ACTIVE until owning Context contract, data classification, output schema, approval mode, evaluation dataset and manual fallback exist.
