# 1. Supported patterns

Contextual side panel, explicit action buttons, suggestion cards, current-vs-proposed diff, evidence drawer, confidence indicator, accept/edit/reject controls, async job status and unavailable state.

# 2. UX rules

Always label AI-generated content. Never preselect high-impact acceptance. Show data cutoff and evidence. Distinguish draft from sent/committed. Permit correction feedback. Do not expose hidden prompt, secret or provider-specific raw payload.

# 3. Accessibility

Keyboard operation, screen-reader labels, non-color-only confidence/error states, predictable focus and concise Vietnamese copy.
